隐私政策

最后更新：2026 年 9 月 10 日

一、工具输入的数据

本站所有开发工具（JSON 格式化与校验、文本比对、编码解码、正则测试、时间戳转换、哈希计算、 代码格式化、字符串处理、生成器）的解析、转换与计算，全部在你的浏览器内通过 JavaScript 完成。 你在这些工具中输入或粘贴的文本、代码、文件，不会被发送到本站服务器，本站也没有接收这些内容的服务端接口。

涉及文件的功能（文件哈希、图片转 Base64）通过浏览器本地文件读取 API 处理， 文件内容同样不会离开你的设备。

二、访问统计

本站使用第三方服务「不蒜子」（busuanzi.ibruce.info）统计页面访问量， 用于在页脚展示本站总访问量与访客数。该服务在页面加载时接收你的浏览器标识（User-Agent）、 来源页面地址与大致地理位置（由 IP 推导），用于区分访客与统计去重。

本站本身不设置任何用于追踪你的 Cookie，也不建立用户账号体系，不收集姓名、邮箱、手机号等个人信息。 统计脚本在本地预览（file://）与 localhost 调试时不会加载。

三、第三方资源

为了保持页面简洁，本站从公共 CDN 加载以下第三方资源，加载时你的浏览器会与这些服务通信，对方的隐私政策独立适用：

  • cdnjs.cloudflare.com — 提供 CodeMirror 代码编辑器与二维码生成库。
  • busuanzi.ibruce.info — 提供访问量统计。

本站不请求任何其他第三方域名。若你处于对隐私要求极高的环境， 可以拦截上述请求，除访问量计数与代码编辑器的高亮功能外，其余工具功能不受影响。

四、广告

本站未来可能接入广告以覆盖运营成本。接入广告后，广告服务商可能使用 Cookie 或类似技术投放广告， 届时本政策会同步更新，说明服务商名称与其数据用途。本站当前没有投放任何广告。

五、本地存储

本站使用浏览器 localStorage 保存你的主题偏好（亮色 / 暗色），该数据仅保存在你的设备上， 不会同步到任何服务器，清除浏览器数据即可删除。

六、政策变更

本政策如有更新，会修改本页顶部的"最后更新"日期。继续使用本站即表示你接受更新后的政策。

七、联系方式

对本政策有疑问，或希望反馈数据相关的问题，可以通过项目仓库 提交 Issue 联系。
