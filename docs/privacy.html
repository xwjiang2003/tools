隐私政策

最后更新：2026 年 9 月 10 日

一、工具输入的数据

本站所有开发工具（JSON 格式化与校验、文本比对、编码解码、正则测试、时间戳转换、哈希计算、 代码格式化、字符串处理、生成器）的解析、转换与计算，全部在你的浏览器内通过 JavaScript 完成。 你在这些工具中输入或粘贴的文本、代码、文件，不会被发送到本站服务器，本站也没有接收这些内容的服务端接口。

涉及文件的功能（文件哈希、图片转 Base64）通过浏览器本地文件读取 API 处理， 文件内容同样不会离开你的设备。

二、访问统计

本站使用两个第三方统计服务，用于了解访问量、来源与页面热度：

  • 不蒜子（busuanzi.ibruce.info）—— 用于页脚展示本站总访问量与访客数。 该服务在页面加载时接收你的浏览器标识（User-Agent）、来源页面地址， 以及由 IP 推导的大致地理位置，用于区分访客与统计去重。
  • 百度统计（hm.baidu.com）—— 用于分析访问来源、地域分布、访问设备与各工具页的热度。 该服务会在你的浏览器中写入 Cookie（例如 HMACCOUNT、Hm_lvt_*、 Hm_lpvt_*）以识别回访用户，并收集你的 IP 地址、浏览器与操作系统信息、 来源页面以及在本站内的访问路径。

本站不建立用户账号体系，不收集姓名、邮箱、手机号等个人信息。 若你不希望被统计，可以通过浏览器设置或扩展拦截 hm.baidu.com 与 busuanzi.ibruce.info 的请求，或启用浏览器的「请勿追踪」类隐私保护功能—— 这不影响任何工具的使用。

三、第三方资源

为了保持页面简洁，本站从公共 CDN 加载以下第三方资源，加载时你的浏览器会与这些服务通信，对方的隐私政策独立适用：

  • cdn.jsdelivr.net — 提供 YAML / TOML 等格式转换库的按需加载（仅在对应工具页）。
  • busuanzi.ibruce.info — 页脚访问量统计。
  • hm.baidu.com — 百度统计，站点分析。

代码编辑器（CodeMirror）与二维码生成库原先由 cdnjs.cloudflare.com 提供， 现已改为由本站自身域名下的 /assets/cdn/ 目录提供——加载它们不会再与 Cloudflare 通信。

除以上三个域名外，本站不请求其他第三方资源。若你处于对隐私要求极高的环境， 可以拦截上述请求，除访问量计数与代码编辑器的语法高亮外，其余工具功能不受影响 （所有工具的计算逻辑都在本地完成，不依赖这些外部资源）。

四、广告

本站未来可能接入广告以覆盖运营成本。接入广告后，广告服务商可能使用 Cookie 或类似技术投放广告， 届时本政策会同步更新，说明服务商名称与其数据用途。本站当前没有投放任何广告。

五、Cookie 与本地存储

本站自身不写入任何 Cookie。唯一的 Cookie 来自上文所述的百度统计， 用于区分独立访客与识别回访，你可以随时在浏览器中清除或屏蔽。

另外，本站使用浏览器 localStorage 保存两项偏好，它们仅保存在你的设备上， 不会同步到任何服务器，清除浏览器数据即可删除：

  • 主题偏好（亮色 / 暗色）；
  • 语言偏好（中文 / English），用于记住你手动选择的语言、避免每次访问都被自动跳转。

六、政策变更

本政策如有更新，会修改本页顶部的"最后更新"日期。继续使用本站即表示你接受更新后的政策。
