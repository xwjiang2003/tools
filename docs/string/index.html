在线字符串与文本处理

面向日常文本整理的杂活：转大小写、换命名风格、按行排序、去重、批量加前缀、统计字数。左侧输入文本，右侧选择操作，结果即时生成。

处理在浏览器本地完成，文本内容不会上传。

主要功能

  • 大小写与命名：大写、小写、首字母大写，以及驼峰、下划线等命名风格互转。
  • 排序：按行排序，支持按字母、按长度以及随机打乱。
  • 去重：按行去重，可选择是否保留空行与仅含空白的行。
  • 查找替换：支持普通文本与正则表达式替换，并可预览匹配结果。
  • 分割与合并：按分隔符或固定长度切分文本，也能把多行合并成一行。
  • 行操作：为每行添加前缀、后缀或行号，起始值与格式可自定义。
  • 实时统计：边输入边显示字符数、单词数、行数与 UTF-8 字节数。

使用步骤

  1. 在左侧粘贴或输入要处理的文本。
  2. 在右侧选择操作类别，例如大小写、排序、去重、替换、分割合并或行操作。
  3. 按操作需要填写分隔符、前缀等参数。
  4. 在结果面板查看输出并复制。

常见问题

字节数是怎么计算的？

按 UTF-8 编码计算。一个 ASCII 字符占 1 字节，常见汉字占 3 字节，emoji 等增补平面字符通常占 4 字节。所以中文文本的字节数会明显大于字符数。

支持用正则做查找替换吗？

支持。选择替换操作后可以使用正则表达式，并按 $1 $2 的形式引用捕获分组。

去重时保留的是第一次还是最后一次出现的行？

默认保留第一次出现的行，后续重复行被移除，因此结果中行的先后顺序保持不变。

文本很长时会卡吗？

几万行以内的常规文本处理是即时的。如果需要处理更大的文本，建议分块处理，避免浏览器一次性构造过大的字符串。
