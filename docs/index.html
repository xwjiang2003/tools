JSON 在线格式化、校验与转换工具

这是一个纯浏览器端的 JSON 工具箱，把日常处理 JSON 时最常用的几件事放在同一个界面里：格式化、压缩、校验、排序、转义、树视图，以及 JSON 比对、格式转换和 JSONPath 查询。

所有解析与转换都在你的浏览器里完成，JSON 内容不会发送到任何服务器。对经常要粘贴接口返回、配置文件或日志片段的场景来说，这一点比功能多寡更重要。

主要功能

  • 格式化与压缩 — 按 2 空格 / 4 空格 / Tab 缩进美化；或压成一行并显示压缩前后体积与压缩率。
  • 语法校验 — 解析失败时给出错误信息与出错位置，并附带结构概览，方便快速定位漏写的引号或逗号。
  • 递归排序 — 按 key 的字母顺序递归排序整个对象树，支持升序与降序，常用于比对两份配置。
  • 转义 / 去转义 — JSON 字符串的 escape 与 unescape，逐字符处理，避免正则替换带来的边界问题。
  • 树视图 — 可折叠展开的树形结构，标注每个节点的数据类型，支持一键展开或折叠全部。
  • JSON 比对 — 左右两份 JSON 做行级差异比对；开启"语义比对"后可忽略 key 顺序带来的假差异。
  • 格式转换 — JSON 与 CSV、XML、YAML 之间双向转换，转换方向可一键互换。
  • JSONPath 查询 — 支持 $.key、[*]、.. 递归、过滤器 [?(@.price>100)]、数组切片与多索引。

使用步骤

  1. 在左侧编辑器中粘贴或输入 JSON 文本，也可以点"示例"载入一份演示数据。
  2. 在右侧选择"基础操作 / 比对 / 转换 / JSONPath"标签页。
  3. 基础操作下点击格式化、压缩、校验等按钮，结果会显示在下方结果面板。
  4. 比对与转换需要左右两份输入，按提示分别填写后点击执行。

常见问题

我的 JSON 数据会被上传吗？

不会。解析、格式化、比对、转换全部由浏览器里的 JavaScript 完成，页面没有把 JSON 内容发往任何后端的代码。你可以断网后继续使用本页功能（首次加载需要网络获取编辑器依赖）。

JSON 校验失败，但看起来没什么问题？

最常见的四个原因是：对象或数组最后一项多了逗号、用了单引号而不是双引号、字符串里出现了未转义的换行、以及文件开头带了 BOM 不可见字符。校验失败时页面会给出出错位置，把光标移到那里通常就能看到问题。

JSON 和 JavaScript 对象字面量有什么区别？

JSON 的 key 必须用双引号，不能有尾随逗号，不能写注释，也不支持 undefined、函数和单引号字符串。对象字面量则允许这些写法，所以直接复制 JS 代码里的对象往往无法通过 JSON 校验。

能处理多大的 JSON？

取决于浏览器可用内存，一般几十 MB 的文本没问题。如果文件达到数百 MB，建议改用命令行工具（如 jq），浏览器编辑器在那种体量下会明显卡顿。

全部在线开发工具

本站不止一个 JSON 工具。除 JSON 格式化与转换外，还有编码解码、哈希加密、正则测试、时间戳与时区换算、各类 ID 解析、格式转换与代码格式化等工具，全部在浏览器本地运行，粘贴的内容不会上传服务器。按分类列出如下：

格式转换

  • 代码格式化 — HTML / CSS / JS / SQL 代码格式化
  • JSON↔YAML — JSON 与 YAML 双向转换
  • JSON↔TOML — JSON 与 TOML 双向转换
  • JSON↔CSV — JSON 与 CSV 双向转换，可选是否带表头
  • 颜色转换 — HEX / RGB / HSL 颜色互转与配色预览

进制转换

  • 任意进制转换 — 2–36 任意进制之间互转
  • 二进制转换 — 二进制、十进制、十六进制换算
  • 十六进制转换 — 十六进制与文本、十进制互转

编码 / 加密

  • 编码解码 — Base64、URL、Unicode、HTML 实体编解码
  • 加密哈希 — MD5 / SHA 系列、HMAC、AES 与文件校验值
  • JWT 解码 — JWT 解码与 HS256 / 384 / 512 签名校验

文本 / 字符串

  • 文本比对 — 逐字符 / 逐词比对两段文本的差异
  • 字符串 — 大小写转换、去重、排序与字数统计
  • 正则表达式 — 在线测试正则，实时高亮匹配与替换预览
  • 命名风格 — camelCase、snake_case 等命名风格互转

代码 / 生成

  • 生成器 — UUID、随机密码与二维码生成
  • 代码片段 — 常用语言的代码片段速查

时间 / 日期

  • 时间戳 — Unix 时间戳与日期互转，秒 / 毫秒自动识别
  • 批量时间戳 — 批量时间戳与日期互转
  • 时间戳速查 — 今天 / 本周 / 本月等常用时间戳速查
  • 时区转换 — 两个城市之间的时区换算与当前时间对照
  • ISO 周数 — ISO 周数与日期互查
  • 年内第几天 — 年内第几天与日期互查
  • 闰年天数 — 闰年判断与某年的天数
  • 世界时钟 — 多城市世界时钟，支持多个视图
  • 倒计时 — 到指定日期的倒计时
  • 日期差值 — 两个日期相差多少天 / 月 / 年
  • 日期加减 — 日期加减天数与工作日推算
  • 时长换算 — 秒、分、时、天之间的时长换算

ID / 标识

  • UUID — UUID v4 / v7 批量生成与解析
  • Snowflake — Snowflake ID 反解时间戳与机器号
  • Twitter ID — Twitter Snowflake ID 转发布时间
  • ObjectId — MongoDB ObjectId 内嵌时间戳解析
  • Firebase ID — Firebase Push ID 的生成时间解析

速查表
