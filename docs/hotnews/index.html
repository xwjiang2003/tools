今日科技热榜：实时科技资讯聚合

这个页面把当天最值得看的科技资讯集中在一处。中文来源覆盖 IT之家、少数派、InfoQ、开源中国、Solidot、爱范儿、钛媒体与雷峰网，英文来源覆盖 Hacker News、TechCrunch、The Verge 与 Ars Technica。每条都保留指向原站的链接，点标题即在新标签页打开原文；本站只做聚合与排版，不转载正文，版权归原媒体所有。

内容每天北京时间 08:00 抓取一次，结果在构建期直接写进 HTML。因此页面不依赖任何接口，打开就完整可见，爬虫不执行 JavaScript 也能读到全部条目；不需要注册登录，没有弹窗、没有插屏广告，也不写入任何 Cookie。

主要功能

  • 按来源分组：12 个来源各自成组，顶部标签可一键只看其中一家，默认「全部」依次列出。
  • 直达原文：每条标题都是指向原站的链接，新标签页打开，不经过中间页跳转。
  • 每天 08:00 更新：定时任务在每天早上八点抓取并重建页面，打开就是当天的最新内容。
  • 带热度信息：Hacker News 条目附带站内得票数，可据此判断这条在开发者社区的实际讨论热度。
  • 抓取失败自动兜底：某个来源临时不可用时会沿用上一次成功抓取的内容并标注时间，页面不会变空。
  • 免注册免安装：纯静态页面，不注册、不安装，也不需要在手机上装任何 App。

使用步骤

  1. 直接在下方列表浏览当天资讯，默认按来源从头到尾全部展开。
  2. 点顶部来源标签可只看某一家媒体，点「全部」回到完整列表。
  3. 点任意标题即在新标签页打开原站文章阅读全文。
  4. 需要具体工具时，用页面顶部导航回到 JSON、正则、时间戳等工具页。

常见问题

热榜多久更新一次？

每天北京时间 08:00 更新一次。定时任务会重新抓取全部来源并重建页面，所以同一时间所有人看到的都是同一份内容，页面顶部显示的就是本次更新时间。

这些资讯是本站发布的吗？

不是。本站只抓取各来源公开的 RSS 摘要，展示标题、摘要与发布时间，完整内容与版权都归原媒体所有，点标题会跳转到原站阅读。如果某家媒体不希望被聚合，可以通过页面上的反馈入口联系，会立即移除。

为什么没有 36 氪和知乎热榜？

36 氪已不再提供 RSS（原订阅地址现在返回网页），其接口还需要签名校验；知乎热榜接口要求登录态。这两者都只能靠模拟客户端抓取，稳定性差且不合规，因此没有收录。其余来源均对接官方 RSS 或公开接口。

列表的排序规则是什么？

直接沿用每个来源自身的顺序。各家榜单本身就是编辑或算法排过的结果——Hacker News 尤其明显，改用时间重排反而会破坏它排名的含义。

打开原文会不会有跳转和广告？

不会。标题链接直接指向原站文章地址，本站不插入任何中间跳转页、不附加推广参数，也不修改目标链接。
